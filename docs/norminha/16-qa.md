# QA e regressão — Norminha V1

Última execução completa: 23/08/2026 · `feat/norminha-v1`

## Como rodar tudo

```bash
# unitários (o teste de API se pula sozinho sem servidor)
php tests/Unit/norminha_todos.php

# com o teste de API, que fala HTTP de verdade
php -S 127.0.0.1:8000 -t . tests/Smoke/router.php &
NORMINHA_API_CREDS=/caminho/creds.json php tests/Unit/norminha_todos.php

# regressão do portal, comparada ao baseline
php tests/Smoke/smoke.php https://desbloqueiacursos.com.br
```

O runner `norminha_todos.php` existe porque o projeto não tem um: com dezesseis arquivos, "rodar
tudo" virava uma linha de comando comprida que alguém um dia digita errado e conclui que passou.
Cada teste roda em processo próprio — uma falha fatal em um não derruba os outros.

## O que os testes provam por mutação

Cada garantia central foi verificada quebrando o código de propósito:

| Quebra | O que caiu |
|---|---|
| Remover checagem de dono no UUID | `NEGA o mesmo uuid para outro aluno` |
| Remover escopo de curso na consulta de item | vazou aula de curso alheio |
| Introduzir `recalcularInscricao()` | varredura de código **e** `Com_insert 0 → 1` |
| Forçar rótulo "Você parou em" | mostrou o texto exato que iria ao aluno |
| Fast-path chamar o gerador | contador de IA: esperava 0, recebeu 1 |
| Trocar janela SQL por `date()` do PHP | contagem vazia |
| Remover guarda de "desligado" no provedor | tentou a rede de verdade |
| Ler token em cache no lugar errado | esperava 900, recebeu null |

## Cobertura manual — frontend

Não automatizada. Precisa ser feita antes do go-live:

- [ ] abrir, minimizar e reabrir; preferência preservada após recarregar
- [ ] as quatro ações rápidas, conferindo cada número contra a tela do curso
- [ ] "Tirar dúvida desta aula" aparece só em aula
- [ ] indicador "pensando", erro com botão de repetir, 429
- [ ] mensagem com `<script>` renderizada como texto
- [ ] 320 / 375 / 430 px e desktop
- [ ] IA ligada e desligada
- [ ] áudio presente e ausente
- [ ] widget aparece uma única vez em cada tema

## Limitações conhecidas

1. **Nenhum teste toca o modelo real.** Tudo roda contra dublê — a IA está desligada e o modelo nem
   foi escolhido. O Checkpoint 1 exige revisar manualmente uma amostra de respostas reais.
2. **Concorrência não foi testada sob carga real.** O rate limit é atômico por `ON DUPLICATE KEY
   UPDATE`, mas os testes são sequenciais.
3. **O modo autenticado do smoke** depende de credenciais de teste; sem elas ele se pula.
4. **`/v2/como-funciona-a-sala-virtual`** segue com defeito conhecido registrado (rota viva,
   página excluída).
